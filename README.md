# Wesley’s portfolio

Open `index.html` to preview the site. The pages use static HTML and share one stylesheet. About includes an in-browser résumé preview.

## Add a playable app

Host the app online or place its static files under `apps/<app-name>/`. Add a
Play button on the corresponding project detail page and point it to the app’s
hosted URL or its relative entry path.

```html
<a class="button primary" href="apps/app-name/index.html">Play App name</a>
```
